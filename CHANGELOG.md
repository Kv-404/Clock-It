# Changelog

Versions follow [semantic versioning](https://semver.org). The live site at [clockit.kv404.dev](https://clockit.kv404.dev) tracks the latest `1.0.x` release on `main`. Security support is described in [SECURITY.md](SECURITY.md).

## 1.0.0 — 2026-10-11

First supported public version.

- Browser camera studio with playful filters, Hands, Face, and Full modes.
- Guests can use the studio. Sign-in is required to save a photo, record a video, or open the gallery.
- Saved captures stay private, are served from this site, and expire after two hours.
